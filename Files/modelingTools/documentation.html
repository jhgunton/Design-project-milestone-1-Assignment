1 Build and run a model

The library turns a declared reaction network into differential equations, checks declared units, integrates the equations with exact dose events, and returns time courses for plotting and analysis. You still choose the biological assumptions, stoichiometry, numerical parameter values, and initial conditions. Start with a diagram, then declare compartments, species, reactions, and parameters.

This complete toy model describes a cleared chemical in a 2 L compartment. It runs independently of the design project.

import numpy as np
from modelingTools import (
    KineticModel, Compartment, Parameters, Reaction,
    Simulation, Impulse, plot_simulations,
)

network = KineticModel()
network.add_compartment(Compartment('fluid', volume=2.0))
network.add_species('B', 'Chemical in fluid', 'M', 'fluid')
network.add_reaction(Reaction('Clearance', 'B', {},
                              forward_rate_constant='k_loss'))
parameters = Parameters()
parameters.add('k_loss', np.log(2) / 60, 'min^-1', '60-minute half-life')
network.add_accumulator('AUC_B', lambda s, k: s.B, 'M min', 'Exposure')
model = network.compile(parameters, time_units='min')

result = Simulation(
    'One dose', np.linspace(0, 180, 361), model,
    initial_values={'B': 0.0},
    impulses=[Impulse(0, 'B', 2e-9, 'mol')],
).simulate()
print(result['B'][0])       # 1e-9 M: 2e-9 mol distributed in 2 L
print(result['AUC_B'][-1])  # integrated concentration in M min
plot_simulations(result, variables=['B'], time_units='min')

2 Units and compartments

All volumes are in liters. Bulk species use molar concentration; replicated cell compartments use molecules per cell. Adding a counted compartment automatically creates its count state; do not declare that count with add_species. A dimer's value counts dimers; specify two monomers in the reaction when a dimer contains two receptor subunits.

DeclarationMeaning
Compartment('blood', volume=5.0)One bulk compartment with a fixed 5 L volume.
Compartment('cell', count_variable='N', count_units='cells', volume_per_unit=1e-12)A replicated cell compartment; creates the count state N in cells, with 1e-12 L per cell.
add_species('B', 'Blood chemical', 'M', 'blood')Molar concentration in blood.
add_species('R', 'Receptor', '#/cell', 'cell')Receptor molecules per cell.

Use add_compartment(Compartment(...)) for both forms. Supply exactly one of volume and count_variable. A counted compartment owns its count state; count_units defaults to cells, and count_description supplies an optional count label. These count options are unavailable for fixed-volume compartments. Declare molecular species separately with their compartment names.

volume_per_unit is required when converting per-cell amounts to intracellular concentration. Do not use total tumor volume for that conversion.

Choose a simulation time unit: sec, min, hr, or day (the parser also accepts their documented aliases). Unit checks identify inconsistent declared time units; they do not automatically convert a parameter value reported per second into a model running in minutes.

The chemical count symbol # means molecules, not moles. With AVOGADRO in molecules/mol, an intracellular amount x in #/cell has concentration x/(AVOGADRO * cell_volume_L). Bulk amount is concentration * volume.

3 Parameters and conversions

parameters = Parameters()
parameters.add('k_on', 2e6, 'M^-1 min^-1', 'Association')
parameters.add('k_off', 0.02, 'min^-1', 'Dissociation')
print(parameters['k_off'])       # numerical value
print(parameters.k_off)          # same value
print(parameters.units('k_off')) # declared units
print(parameters.parameter('k_off'))
variant = parameters.with_changes(k_off=0.01)  # original is unchanged

add(name, value, units, description='') declares a new parameter; duplicate names raise an error. with_changes(**changes) changes values of existing parameters while retaining their units and descriptions. Build a new model with the changed table; changing a separate table does not change an existing model.

from modelingTools import convert_rate_constant

# First convert per second to per minute if needed.
k_on_M = 1e5 * 60
k_on_per_cell = convert_rate_constant(
    k_on_M, 'M^-1 min^-1', '(#/cell)^-1 min^-1', volume=5e-13
)

convert_rate_constant(value, from_units, to_units, volume) converts between molar and per-cell forms using AVOGADRO * volume and prints its factor. For a reaction between two per-cell species, a molar association constant is divided by that factor. For mixed bulk/per-cell binding, k_on * [bulk] * [receptor] already has units #/cell/time, so keep k_on in M^-1/time. This helper does not convert time units: change seconds to minutes separately.

Other utilities are Unit(text) (unit arithmetic and comparison), unit_of_species(units), time_unit_in(units_string), and check_time_units(units, time_units, what). Use 1 for a dimensionless parameter. Typical strings include M, #/cell, cells, min^-1, M^-1 min^-1, (#/cell)^-1 min^-1, mol, and M min.

4 Reactions and custom rates

network.add_reaction(Reaction(
    'Dimerization', '2 R', 'D',
    forward_rate_constant='k_on', reverse_rate_constant='k_off',
))
network.add_reaction(Reaction('Synthesis', {}, 'R',
                              forward_rate_constant='q_R'))
network.add_reaction(Reaction('Loss', 'R', {},
                              forward_rate_constant='k_deg'))

Reaction(name, reactants, products, forward_rate_constant=None, reverse_rate_constant=None, ...) accepts reaction sides as strings or dictionaries, such as '2 R' or {'R': 2}. Use {} for an empty side. Stoichiometric coefficients are nonnegative integers. Reactions must use species already declared in the network. Adding a reaction, observable, or accumulator with the name of an existing one replaces it and prints a warning; rebuild the model afterward so it uses the new version.

Mass action generates k times each reactant raised to its stoichiometric coefficient. Thus 2 R -> D uses k_on * R**2, consumes two R per event, and produces one D. A reversible reaction uses the product species for its reverse rate. There is no extra combinatorial factor of one half.

For a non-mass-action rate, supply a smooth function, a displayed expression, and the units returned by the function:

network.add_reaction(Reaction(
    'Saturable removal', 'R', {},
    rate_function=lambda s, k: k.v_max * s.R / (k.K_R + s.R),
    rate_expression='v_max [R] / (K_R + [R])',
    rate_units='#/cell/min',
))

Here R and K_R have the same per-cell units, and v_max is #/cell/min. The library checks rate_units but cannot infer dimensions inside the Python function. For a custom reverse direction, use reverse_rate_function and reverse_rate_expression. Optional rate_expression_latex and reverse_rate_expression_latex improve mathematical display.

The reference rate is #/cell/time if any participant is a per-cell species, M/time if all participants are bulk species, or cells/time for reactions on a count. The library multiplies by the cell count or donor bulk volume to conserve molecules when converting between compartments. A transfer between bulk compartments uses its first participant's compartment as the reference; write the donor first.

For a smooth threshold, smooth_step(x, threshold, width) returns a logistic switch between zero and one. Avoid a discontinuous Python if inside a rate law. A direct contribution to one declared derivative can be added with network.add_rate_term(species, function, expression, units, description=''); it is a source or sink in moiety bookkeeping, not a separate reaction.

5 State conversions observables and accumulators

Custom rate functions receive s, a State, and k, a Parameters table. Both support dictionary and attribute access.

OperationResult
s.R or s['R']The species value in its declared units.
s.molar('X')Molar concentration; converts #/cell using one cell's volume.
s.per_cell('B', 'cell')Equivalent molecules per cell from bulk concentration and one cell's volume; not total blood molecules divided by N.
s.count('cell')The current count of the replicated compartment.
s.volume('blood')The bulk volume in L. For a replicated compartment, this returns volume per unit.
s.observe('signal')An observable evaluated on the current state.
network.add_observable(
    'X_uM', lambda s, k: s.molar('X') * 1e6,
    'uM', 'Intracellular concentration in micromolar',
)
network.add_accumulator(
    'AUC_B', lambda s, k: s.B, 'M min', 'Blood exposure',
)
network.add_accumulator(
    'Q_loss', lambda s, k: k.k_loss * s.B * 5.0,
    'mol', 'Cumulative chemical loss from 5 L blood',
)

add_observable(name, function, units, description='') reports an algebraic quantity without adding a dynamical state. At reporting time its function may receive arrays, so use NumPy-compatible arithmetic. Return a scalar or one value per output time. Observable units are reporting metadata.

add_accumulator(name, rate_function, units, description='') adds a state whose derivative is the supplied function. Declare the integrated units: M min for a concentration-time integral, mol for an integrated mol/min flux. Accumulators default to zero and do not feed back unless your rate law explicitly uses one. Access both kinds through result['name'].

6 Cell growth and death

network.add_reaction(Reaction('Growth', 'N', '2 N',
                              forward_rate_constant='mu'))
network.add_reaction(Reaction(
    'Death', 'N', {},
    rate_function=lambda s, k: s.observe('delta') * s.N,
    rate_expression='delta [N]', rate_units='cells/min',
))

Keep growth and death as separate, irreversible reactions on the cell count. Dying cells take their associated molecular contents out of the living-cell population, so cell loss alone leaves per-cell amounts unchanged. Do not add another per-cell death sink, or mix a cell-count species and molecular species in the same reaction.

Describe redistribution or release using explicit molecular source reactions. For example, with loss rate delta times N cells/min, a source reaction from empty reactants to X with rate delta times X molecules/cell/min keeps the population's total X constant by redistributing the lost cells' X among survivors. Release into blood instead needs a source for the corresponding blood species, converted to M/min using the cell count, Avogadro's number, and blood volume.

In the design project, cell division leaves the average receptor and drug amounts per living cell unchanged. Use the function supplied beside the project notebook to build a model with this assumption:

from design_project_helpers import build_model
model = build_model(network, parameters, time_units='min')

build_model(network, parameters, time_units='min') turns the declared reactions and parameters into a model ready for simulation and equation inspection. It requires one exponential-growth reaction N -> 2 N governed by mu per replicated compartment. It rejects custom or density-dependent growth and direct count-rate terms. Parameters retain their declared units. The returned model supports the reporting and simulation methods below.

Cell division and molecular balances

All species are integrated in their declared units: M, molecules per cell, or cells. The core library's network.compile(...) includes growth dilution in per-cell equations: dividing existing molecules among more cells decreases the mean amount per cell. The project's build_model omits this dilution, implementing the assumption that growth leaves per-cell amounts unchanged. Cell-loss reactions need no per-cell death loss.

Maintaining per-cell amounts during growth implies a source of cell-associated molecules, including drug payload. Payload accounting therefore balances administered payload plus this implied source against the amounts remaining and removed. This approximation does not conserve administered drug alone. The helper supports the specified exponential growth law; another growth law needs a corresponding implementation.

7 Build and inspect

# General library model; use build_model(...) for the design project.
model = network.compile(parameters, time_units='min')
print(network)
print(parameters)
model.print_rate_equations()
print(model.rate_equation_text())
print(model.stoichiometry_table())
for moiety in model.moieties():
    print(moiety.balance_text)

network.compile(...) builds a runnable model and validates declared species, compartments, parameter references, mass-action dimensions, custom reference-rate units, and time units. It does not prove that your chosen biological model is correct or that a custom function has the dimensions you intended. Inspect the equations against your diagram.

model.species_names and model.accumulator_names list their names. model.species(name) and model.compartment(name) return their declarations. model.rate_equations() returns structured display terms. model.print_parameters() prints the parameter table.

A moiety is a weighted total that the internal reactions transfer without creating or destroying it. Each result gives coefficients, total_text, changed_by, is_conserved, and balance_text. In an open model, sources and sinks generally change the total. Stoichiometric moieties are useful checks, not an automatic numerical conservation test or proof that every species is physically defined correctly.

derivative = model.derivative_function()
rates_in_declared_units = derivative(0.0, {'N': 1e9, 'R': 20000.0})

derivative_function() returns a callable taking time and a state dictionary. Omitted molecular species and accumulators default to zero; include positive counts for compartments with per-cell molecular species. Its returned dictionary gives each derivative in the species' declared units per simulation time. model.rhs(t, state) accepts and returns vectors in the same units, ordered by model.state_names. model.initial_state(initial_values) creates this vector, and model.state(state) wraps it for named access. totals_from_declared and declared_from_totals convert between declared values and population totals when needed for analysis.

8 Simulations impulses and repeated doses

trial = Simulation(
    condition_name='My condition',
    t=np.linspace(0, 63 * 1440, 1001),
    model=model,
    initial_values={'N': 1e9, 'R': 20000.0},
    impulses=[],
    method='LSODA', rtol=1e-8,
)
trial.print_initial_conditions()
result = trial.simulate()

The time grid must be strictly increasing with at least two values. It controls reported samples, not the solver's adaptive internal step size. Give every compartment with per-cell molecular species a positive initial count. Count-only populations, unlisted molecular species, and accumulators may start at zero. Parameters and counts must remain physically sensible over the simulation; the solver does not enforce nonnegativity.

rtol and atol are integration tolerances. The default method is LSODA. For reaction-network models, absolute tolerance uses each state variable's declared units. With atol=None, the defaults are 1e-20 M, 1e-8 molecules/cell, and 1e-8 cells. A dictionary overrides selected states, for example atol={'B': 1e-24, 'N': 1e-12}; other states retain their defaults. A scalar applies to every species in its own units. Choose tolerances small enough to resolve the concentrations and counts relevant to your model. accumulator_atol=1e-30 sets the default for accumulators in their integrated units; a named atol entry can override it. result.atol_used records the tolerance for each state variable.

events = [Impulse(day * 1440, 'B', 2e-9, 'mol') for day in [0, 21, 42]]
result = Simulation('Three doses', time_axis, model, initial_values,
                    impulses=events).simulate()

from modelingTools import Regimen
course = Regimen('B', amount=2e-9, units='mol', interval=21*1440,
                 start=0, number_of_impulses=3)
events = course.impulses(last_time=63*1440)

The current Milestone 1 protocol uses three equal doses on days 0, 21, and 42, with assessment on day 63. The notebook's dosing explorer runs the student's model and untreated initial values; its reset button restores this calendar.

Impulse(time, species, amount, units) is an instantaneous additive change. For a molar species, supported input units are mol, molecules, or M; for a per-cell species, #/cell or molecules; and for a count, cells. An impulse does not change a parameter, reset a concentration, or represent a finite infusion. An amount in mol is divided by the destination bulk volume to give its M jump.

A count-only impulse retains the compartment's molecular totals, so its per-cell amounts change in inverse proportion to the count. Add molecular cargo separately when adding cells with specified contents. A count impulse must leave compartments with per-cell species at positive counts; count-only populations may reach zero.

Impulse times are inserted into the output grid exactly. A later event has a before and after state at the same time; an event at the initial time is applied before the first recorded state. Regimen represents repeated impulses; its optional end is exclusive, and number_of_impulses caps the count. Pass either an expanded list or a Regimen directly in the impulses list. Use the model's time units for every event and interval.

9 Results plots and parameter comparisons

days = result.in_days()
final_count = result['N'][-1]
peak_B = result['B'].max()
auc_B = result['AUC_B'][-1]
print(result.impulse_times)
print(result.names())

plot_simulations(
    [first_result, second_result], variables=['B', 'N'],
    time_units='day', columns=2, figsize=(10, 4),
    overall_title='Compare conditions', log_scale=False,
)

result['name'] returns a NumPy time series for a species, observable, or accumulator. result.t is time in simulation units; time_in('day'), in_days(), and in_hours() convert the axis. result.units and result.descriptions provide labels. result.totals calculates molecular totals from the reported values: molecules/cell times cell count, or M times volume times Avogadro's number. Counts and accumulators retain their own units.

result.at(name, time) returns the last sample at or before that time without interpolation. At an impulse time this selects the after-dose sample. Inspect the duplicate event indices if you need the before-dose value.

plot_simulations(results, variables=None, time_units=None, figsize=(15,10), log_scale=False, overall_title=None, legend_style='shared', time_range=None, columns=3, unit_conversions=None) accepts one result or a list. Variables may include observables and accumulators. Log-scale options are True, False, 'logx', 'logy', or 'loglog'. time_range uses the requested plotting time unit. unit_conversions maps a plotted variable to a (factor, units_label) pair: for example, unit_conversions={'B': (1e9, 'nM')} plots a molar species B in nM. You may also use Matplotlib directly. make_plot_look_good(axes) and set_axes_labels(axes, x_label, y_label, title, legend_title=None) provide optional consistent styling.

results = []
for k_loss in [0.005, 0.01, 0.02]:

Keep initial conditions and dosing consistent when comparing parameter effects. If a parameter changes the untreated receptor state, recompute that state for the variant before treatment. For design-project variants, use build_model(network, variant_parameters, time_units='min').

10 Common problems and advanced interfaces

SymptomWhat to inspect
Missing compartment or count errorAdding a counted compartment creates its count state. Compartments with per-cell molecular species need positive initial counts; count-only populations may start at zero.
Unit mismatch when building a modelSeconds versus minutes; per-cell versus molar association constants; the units returned by a custom rate.
Killing is always saturated or absentConvert molecules/cell to intracellular M before comparing with a molar potency parameter.
A dose is too large by a volume factorDistinguish amount in mol from concentration in M. Use the correct destination volume.
Doses disappear or seem to reset blood concentrationPass all additive impulses to one simulation. Do not restart each cycle with zero drug unless that is the intended model.
Spurious per-cell loss with deathCell-loss reactions leave per-cell amounts unchanged; do not also add death sinks for every per-cell pool.
Cell division changes per-cell amounts unexpectedlyFor the project, use build_model and its required exponential-growth reaction.
Negative counts or strange concentrations near extinctionInspect solver tolerances, model validity at tiny counts, and the chosen time window.
Plot misses an early peakUse denser output near dose events; adaptive internal steps do not guarantee a densely sampled plotted peak.

For hand-written ODEs, HandWrittenModel(derivative_function, species, time_units='min') accepts a function dydt(t, state_dict) returning a derivative dictionary, and an ordered list of state names. It has no automatic unit or compartment bookkeeping, observables, or accumulators. Impulses use units='raw'. In this interface, implement the intended no-dilution equations directly; the project adapter is for reaction-network models.

Declaration objects ChemicalSpecies, PopulationCount, Parameter, DirectTerm, Observable, and Accumulator are normally created by the corresponding add methods. CompiledModel, RateEquation, RateTerm, and Moiety support inspection and extension; most assignments do not require constructing them directly.

Use Python help(...) for exact signatures and docstrings. This guide matches modelingTools 0.1.0a10. Its examples use illustrative values and establish software behavior, not fitted biological parameters.

Assignment snapshots

For instructors maintaining assignments.

Each assignment keeps a complete copy of this package beside its authored notebooks, including this HTML guide and its PDF. Its build ships that local copy in Files/modelingTools/, so the released assignment does not depend on the repository or an installed modeling library.

From the repository root, pin a new assignment:

python -m psetTools.snapshot_modeling_tools PSET_4

To deliberately update an existing assignment's version:

python -m psetTools.snapshot_modeling_tools PSET_4 --refresh
python -m psetTools.snapshot_modeling_tools "Design Project/2026 20.320 project" --refresh

The command regenerates the PDF from documentation.html, copies the package, and writes SNAPSHOT.json with its version and file hashes. Assignment builds verify their local snapshot and never refresh it automatically. An edited or incomplete snapshot fails validation. Its files are recorded in the build manifest, so refreshing one assignment triggers a rebuild of that assignment.

Edit this maintained source, increment __version__ when its behavior or interface changes, and explicitly refresh only the assignments that should receive that change. Leave older snapshots in place to reproduce older assignments.

Version history

0.1.0a1. Packaged the unchanged modeling implementation from the design-project-2026-alpha tag. PROVENANCE.json records that original module's commit and checksum.

0.1.0a2. Removes the numerical balance checker and its BalanceWarning. Simulations retain model validation and explicit solver-failure reporting. Stoichiometry, molecular-balance descriptions, and equation displays remain available.

0.1.0a3. Allows regimens with no doses in the simulated period, scalar constant observables, and models with no reactions or direct rate terms. Accepts dimensionless units written as "1" and integer-valued stoichiometric coefficients such as 2.0 in dictionaries and reaction strings.

0.1.0a4. Names the top-level model declaration object KineticModel. It combines compartments, species, reactions, direct rate terms, observables, and accumulators; compile() produces a CompiledModel for simulation.

0.1.0a5. Uses Impulse for an instantaneous state addition, Simulation(..., impulses=...) for its inputs, and result.impulse_times for the event times. The scheduling helpers and model interface use the same terminology. These names replace the previous dose-based API.
